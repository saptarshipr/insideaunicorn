# Inside a Unicorn

The website for *Inside a Unicorn* by Saptarshi Prakash. Live at https://insideaunicorn.com

## Updating the site

Open this repository in Claude Code or Codex and describe the change, for example "change the Amazon link to ..." or "add a reviews section below the author bio". Ask it to commit and push to `main`. The site updates in about a minute.

To edit by hand, change `index.html` on GitHub (pencil icon) and commit to `main`.

See `AGENTS.md` for how the site is put together.
